# Myanmar Movies Hub — Partnership Letters

## Zaw အတွက် ရှင်းလင်းချက် (မြန်မာ)

မင်း ဒီမနက်မေးခဲ့တယ် — "ကိုယ့် site မှာ video တွေ download ဆွဲပြီး ကိုယ့်ဟာအဖြစ် ပြန်တင်ချင်တယ်" ဆိုတာ။
အမှန်တိုင်းပြောရရင်: Mahar နဲ့ HEY Play ရဲ့ ဇာတ်ကားတွေကို ခွင့်ပြုချက်မရှိဘဲ download ဆွဲ ပြန်တင်တာဟာ
တရားမဝင်ဘူး (piracy) — ဒါကို ငါ မလုပ်ပေးနိုင်ဘူး၊ လုပ်ရင်လည်း site အပိတ်ခံရမယ်၊ AdSense ban မယ်။

**ဒီစာတွေက တရားဝင်လမ်း:** သူတို့ဆီကိုပဲ တိုက်ရိုက်မေးတာ —
(၁) သူတို့ YouTube မှာ အခမဲ့တင်ထားတဲ့ content တွေကို ငါတို့ site မှာ ဆက်ပြီး ဖော်ပြခွင့် (credit အပြည့်နဲ့၊ link ပြန်ပေးနဲ့),
(၂) poster/thumbnail တွေ သုံးခွင့်,
(၃) partner/affiliate/license program ရှိမရှိ — ဒါက မင်းလိုချင်တဲ့ "ကိုယ့် site မှာ video ရှိစေချင်တာ" ကို
တရားဝင်နည်းနဲ့ ရနိုင်တဲ့ တစ်ခုတည်းသောလမ်း။

**မျှော်လင့်ချက် အမှန်:** ဒါ long shot ပဲ — ပြန်မဖြေတာ၊ ဒါမှမဟုတ် "မရဘူး" လို့ ယဉ်ကျေးစွာ ငြင်းတာက
အဖြစ်များဆုံး။ ဒါပေမဲ့ မေးတာ အခမဲ့ပဲ၊ ရရင် အနိုင်ပဲ။ Download-ဆွဲ-ပြန်တင် ခွင့်တောင်းထားတာ မဟုတ်ဘူး —
ဘယ် studio မဆို fan site ကို အဲဒါပေးမှာ မဟုတ်လို့။ Partner program/API ရှိရင် အဲဒါက အစားထိုးလမ်း။

**ဘယ်လိုပို့မလဲ:** သူတို့ရဲ့ official Facebook page message ဒါမှမဟုတ် website မှာပါတဲ့ business email ကို

Subject: Partnership inquiry — Myanmar Movies Hub featuring Mahar's official films

Dear Mahar team,

My name is Zaw, and I run Myanmar Movies Hub (https://luuzoe.github.io/myanmar-movies-hub/),
a Burmese-language film discovery website for Myanmar audiences.
